## Project Overview

This project investigates whether defensive density (the number of defending players clustered around the ball) significantly drags down shot quality (Expected Goals, or xG). We use computer-vision extracted spatial tracking data (360 freeze frames) from the UEFA Euro 2020 tournament, sourced from the StatsBomb Open Data API.

## Repository Structure

* `cse558_project_notebook.ipynb`: The complete Google Colab notebook containing the data extraction pipeline, statistical hypothesis testing (Welch t-tests), and EDA visualizations.

* `statsbomb_360_shots_xg.csv`: The final processed dataset containing 401 open-play shots with spatial features.

* `fig_density.pdf` & `fig_distance.pdf`: EDA plots generated by the notebook.

* `cse558_project_report.pdf`: The final compiled LaTeX project report.

## Dataset

The data is sourced from the open-source StatsBomb GitHub repository and accessed via their official Python API wrapper (`statsbombpy`). We extract Euro 2020 matches (competition ID 55, season ID 43).

## Instructions to Reproduce

You can view and run the entire pipeline via the provided Jupyter Notebook.

**1. Setup Environment**
Open `cse558_project_notebook.ipynb` in Google Colab or a local Jupyter environment. Ensure the following dependencies are installed (the first cell handles this):

```
pip install statsbombpy pandas numpy scipy matplotlib seaborn

```

**2. Extract the Data**
Run the data extraction cell. This loop requests match event logs and 360 tracking frames from the StatsBomb API, calculates the Euclidean distances (shot to goal, and defenders to ball), and exports `statsbomb_360_shots_xg.csv`. 

**3. Run the Analysis**
Run the remaining cells to:

* Calculate descriptive statistics for the report's Basic Questions section.

* Compute the Welch t-test statistics, p-values, and 95% confidence intervals for P1 (Crowded vs Open boxes) and P2 (First-touch vs Delayed shots).

* Generate and export the `.pdf` plots.

## Key Findings

1. **Test 1 (Distance vs Density):** We failed to reject the null hypothesis ($p=0.0767$). Once we controlled for distance (10-18m), crowding the box did not significantly reduce the underlying xG of the shot.

2. **Test 2 (First-touch Advantage):** We rejected the null hypothesis ($p=0.0005$). In crowded penalty boxes, taking a first-touch shot yields a massive +0.087 xG lift compared to delaying the shot.
